Claude 사용량 스티커 — 테마 만들기
====================================

"themes" 폴더 안에 폴더를 하나 만들면 그게 곧 하나의 테마가 됩니다.
우클릭 메뉴 → "테마" 줄에 자동으로 나타나고, 고르면 세션/주간 두 게이지가
그 테마 이미지로 바뀝니다. (마우스를 올리면 이름·퍼센트가 툴팁으로 떠요.)

폴더 구조 예시
--------------
themes/
  tree/              <- 테마 이름 (메뉴에 "tree"로 표시됨)
    stage00.png      <- 잔여량 0%   (예: 잎 하나도 없는 나무)
    stage01.png      <- 잔여량 10%
    ...
    stage10.png      <- 잔여량 100% (예: 잎이 가장 무성한 나무)

규칙
----
1. 이미지는 PNG(배경 투명 권장) 또는 GIF. 한 그루/한 개짜리로 그리세요.
   (사각형 배경 없이 대상만 그리면 스티커에 자연스럽게 얹힙니다.)
2. 파일 "이름 순서"가 곧 단계 순서입니다.
   - 첫 번째 파일 = 잔여량 0% (거의 다 씀)
   - 마지막 파일 = 잔여량 100% (거의 안 씀)
   - stage00, stage01 ... 처럼 0을 채운 숫자로 정렬되게 두는 걸 권장.
3. 장수는 자유. 2장(가득/텅)만 넣어도 되고, 많이 넣을수록 부드럽게 바뀝니다.
   프로그램이 잔여량에 가장 가까운 장을 골라 보여줍니다.
4. 각 이미지의 가로:세로 비율은 같게 맞추세요(세로로 약간 긴 형태 권장).
   두 게이지가 가로로 나란히 배치됩니다.

주의
----
- "잔여량" 기준입니다. 화면 퍼센트는 "사용량"이라, 사용량이 높을수록
  이미지는 텅 빈 쪽(첫 파일 방향)으로 갑니다. (사용 30% => 잔여 70% 이미지)
- 이미지 테마를 쓰려면 Pillow가 필요합니다. exe로 빌드하면 자동 포함되고,
  파이썬으로 직접 실행할 때는:  pip install pillow
- 폴더만 새로 넣고 프로그램을 재시작하면 메뉴에 바로 나타납니다.
- "기본"을 고르면 원래 막대 게이지(세션/주간 2개)로 돌아갑니다.
